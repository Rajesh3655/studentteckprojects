1
Crawlability — Site Returning 403 Error
CRITICAL
Googlebot is likely being blocked (403 Forbidden)

When crawled, the site returns a 403 Client Error. This means Cloudflare (or your hosting firewall) is blocking bot traffic. If Google cannot crawl your pages, your site cannot be indexed, cannot be reviewed by AdSense, and cannot show ads.

→ How to Fix
  • In Cloudflare dashboard → Security → Bots → Enable "Allow verified bots" (Googlebot, AdsBot-Google)
  • Go to Cloudflare → Security → WAF → ensure no rule blocks "Googlebot" or bots with good reputation
  • Create a robots.txt at studenttechprojects.in/robots.txt and ensure it does NOT disallow Googlebot
# /robots.txt — correct setup
User-agent: *
Allow: /

User-agent: Googlebot
Allow: /

User-agent: AdsBot-Google
Allow: /

Sitemap: https://www.studenttechprojects.in/sitemap.xml

Required Pages — About, Contact, Privacy Policy, Terms
CRITICAL
Required trust pages cannot be confirmed as accessible

AdSense requires an accessible About, Contact, Privacy Policy, and Terms of Use page. These pages must be linked from every page (footer or navigation), properly indexed, and contain complete information. The site's 403 block prevented verification of these pages.

→ Minimum Required Content for Each Page
  • About: Who runs the site, what is it about, who is the target audience, why it was created
  • Contact: A working email address or contact form. Physical address optional but increases trust
  • Privacy Policy: Must explicitly mention Google AdSense/cookies, third-party ad serving, and how to opt out
  • Terms of Use: Disclaimers, user responsibilities, content ownership
  • All four pages must appear in your footer and/or navigation on every page
Privacy Policy must contain AdSense-specific disclosures

Google requires your Privacy Policy to explicitly state that third parties (Google) use cookies for advertising, that users can opt out via Google Ads Settings, and that you use Google AdSense. This is a hard requirement per AdSense Program Policies.

AdSense Code Placement
TO VERIFY
AdSense auto-ads code must be in <head> on every page

The AdSense auto-ads snippet must be placed inside the <head> tag of your site's HTML on every page — not just the homepage. If using a CMS, place it in your global header template.

→ Correct AdSense Code Placement
<head>
  <!-- Other meta tags... -->

  <!-- Google AdSense Auto Ads — place in <head> on ALL pages -->
  <script async
    src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX"
    crossorigin="anonymous">
  </script>

  <!-- Replace XXXXXXXXXXXXXXXX with your actual publisher ID -->
</head>
→ Ad Placement Rules (Do NOT violate)
  • Never place ads on pages with no content (e.g., empty category pages)
  • Never place ads in pop-ups, iframes, or emails
  • Do not place ads near navigation buttons where accidental clicks occur
  • Max 3 display ad units per page (best practice; AdSense no longer has a hard limit but quality is enforced)
